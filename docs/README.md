# Governing documentation

This directory will contain the public Florida Politics governing guide and concise provenance suitable for publication.

Private Slack exports, private discussion text, the AP e-book and reproduced AP entries do not belong here. Public rules may identify the controlling AP edition and entry name without reproducing the source text.

The Vale package's implementation status is recorded separately in `coverage/`. A human rule is not represented as automated until the corresponding coverage item is true and names a tested implementation.
