# References

Reference material supports rule research but does not become public merely
because the repository is public.

Appropriate tracked references are concise public links, edition identifiers,
entry names, hashes, licenses and original project summaries. Restricted or
copyrighted source files—including the AP e-book, Slack exports and private
application material—remain outside this directory and outside Git.

Use `docs/RULE_SOURCES.md` for publishable provenance. Create a new tracked
reference only when it adds durable evidence that cannot be expressed there
without copying protected source material.
